---

You are extracting structured facts from a conference abstract. Read the abstract carefully and output one JSON object per distinct factual claim. Do not write a narrative summary.

SCHEMA (version: v1)

Required fields (always fill or use UNKNOWN):
- abstract_id: string — abstract number from the conference programme
- source_id: string — which chunk file this came from
- source_type: "pdf_abstract"
- fact_type: one of: finding | event | announcement | datapoint | claim
- subject: string — who or what this fact is about (company, gene, therapy, institution)
- what: string — 1–2 sentences: what happened or was found (verbatim or close paraphrase)
- evidence_quote: string — verbatim substring of ≤25 words from the abstract that proves this fact. MUST be a literal quote. If you cannot find one, set confidence to "low".
- citation: string — abstract_id + title + conference name + year (e.g. "Abstract 1234. Title. ASGCT 2027.")
- confidence: one of: high | medium | low

Conditional fields (required only when fact_type == "datapoint"):
- quant_value: number
- quant_unit: string (e.g. "patients", "vg/kg", "% response rate")
- quant_context: string — what this number means (e.g. "dose used in Phase 1 trial")

Optional fields (best-effort, leave null if not present):
- modality: one of: gene_therapy | gene_editing | cell_therapy | mRNA | other | null
- disease: string — disease area, free text
- organisation: string — primary institution or company
- geography: string — country or region
- schema_version: "v1"

RULES:
1. One fact per JSON object. Multiple facts from one abstract = multiple objects.
2. Never merge facts from different abstracts.
3. evidence_quote must be a verbatim substring from the source text. If you invent it, set confidence = "low".
4. For datapoint facts: quant_value, quant_unit, quant_context are all required.
5. If a field is unknown, use UNKNOWN (string) for required string fields, null for optional fields.
6. Do not count how many abstracts are in the file. Only extract facts.

OUTPUT FORMAT:
Return a JSON array. Each element is one fact object.

EXAMPLE OUTPUT:
[
